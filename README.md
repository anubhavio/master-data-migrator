# Master Data Migrator

## Overview

Master Data Migrator is a Spring Boot application designed to migrate master/configuration data between two MySQL databases while preserving data integrity and relationships.

This project is being developed as a reusable migration framework that can be extended to support multiple migration scenarios.

## Objectives

- Migrate master data from a source MySQL database to a target MySQL database.
- Preserve parent-child relationships during migration.
- Support automatic ID mapping for auto-generated primary keys.
- Provide a reliable and reusable migration process.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Lombok
